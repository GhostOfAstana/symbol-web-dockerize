# Отчёт браузерной проверки

Дата: 25 октября 2026 года. Использованы уже установленные Chrome 155.0.8059.85 и Playwright из окружения рабочего компьютера; программы не устанавливались. Сервер Go работал во временной папке WSL.

Проверены ширины 375, 768 и 1920 пикселей: горизонтального переполнения страницы нет, скриншоты интерфейса просмотрены. В браузере успешно созданы баннеры каждым из трёх шрифтов. Работают рекомендация шрифта и варианты текста, выбранная подсказка заполняет форму. Необработанных ошибок JavaScript нет.

Без настроенного монитора кнопка показывает понятное сообщение о недоступности, возвращается в доступное состояние, а `/healthz` после запроса отвечает 200. Этот сценарий проверяет веб-интерфейс при отсутствии Docker; он **не является** проверкой реальных метрик контейнера и не заменяет контейнерный сценарий CI.

Исходник: `scripts/browser-smoke.cjs`. Он использует уже доступные Playwright и браузер, ничего не устанавливает.

```sh
node scripts/browser-smoke.cjs http://localhost:8080
```

Необязательные аргументы после адреса: существующая папка для скриншотов, путь к модулю Playwright, путь к браузеру. Только Chromium фактически проверен этим запуском; ручной тест Safari/Firefox/Edge здесь не заявляется.
